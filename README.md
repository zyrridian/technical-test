# Problem Solving Test

Dart implementations for the three supplied problems.

Run an individual solution with:

```text
dart run problem1_lazy_caterer.dart
```

The other solutions follow the same naming convention.

## Notes

- The Lazy Caterer solution returns an empty string for `n < 1`.
- Dense ranking expects the leaderboard in descending order. Gits scores may be in any order.
- Highest palindrome uses recursion and returns `-1` for invalid input or an insufficient change budget.
